# LockedIn web dashboard

Next.js app (App Router, TypeScript, Tailwind) served on Vercel.

Setup steps, environment variables and daily use live in the root [README](../README.md). The build specification is [SPEC.md](../SPEC.md) at the repository root.

## Local development

1. `cp .env.example .env` and fill in the values.
2. `npm install`
3. `npm run dev`, then open http://localhost:3000.
